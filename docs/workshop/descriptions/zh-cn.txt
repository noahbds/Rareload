[h1]Rareload：Garry's Mod 的位置、物品栏与世界存档（v5.0）[/h1]

[h2]简介[/h2]
Rareload 会保存你所在的位置，并在你重生时把你送回那里：你的位置、武器、弹药、生命值、外观和状态，以及你生成的物品、NPC 和载具。每个存档都保留在存档时间线中，你可以回到地图上任何一个更早的时刻。

[b]Rareload 5.0 是完全重写的版本。[/b] v4 的存档和设置不会保留。

[h2]主要功能[/h2]

[b]位置与玩家状态[/b]
[list]
[*] 保存并恢复你的位置、视角和蹲伏状态。
[*] 保留生命值、护甲、武器、弹药、玩家模型、皮肤、身体组件和颜色。
[*] 保留穿墙、冻结和手电筒等状态。无敌和隐身只会还给被允许拥有它们的玩家（默认是管理员），而且恢复永远不会拿走你已经拥有的状态。
[*] 可选：在所有地图上使用相同的武器。
[*] 选择死亡后是否在存档处重生。
[/list]

[b]存档[/b]
[list]
[*] 用工具存档：保存在你瞄准的位置，或你站立的位置。
[*] 有变化时自动存档，间隔和视角变化阈值都可调整。
[*] 可选：离开服务器时自动存档（断开连接、换图或服务器关闭）。
[*] 可选：地图清理前自动存档，这样管理员清理也不会让你的建筑消失。
[/list]

[b]存档时间线[/b]
[list]
[*] 你在这张地图上的所有存档，换图和服务器重启后依然保留。
[*] 搜索、排序和筛选存档；可以置顶并添加备注。
[*] 立即恢复任意存档，可以恢复全部或只恢复部分内容（位置、生命值、武器、弹药、外观、状态、世界）。
[*] 撤销一次恢复。
[*] 选择哪个存档作为你的重生点。
[*] 选择工具的换弹键做什么：回到上一个存档、恢复你的重生点，或恢复上一个存档。
[/list]

[b]物品、NPC 与载具[/b]
[list]
[*] 保存并恢复你生成的物品、实体、NPC 和载具。
[*] NPC 保留 AI 状态、小队和敌人；物体保留生命值、冻结状态和重力。
[*] 物品与载具之间的约束会被恢复。
[*] 仍在地图上的物体绝不会被重复生成。
[*] 浏览任意存档中的物体，并在恢复前在世界中预览存档（绿色 = 空闲，红色 = 被阻挡，蓝色 = 仍在地图上）。
[/list]

[b]载具[/b]
[list]
[*] 支持 Source、Simfphys、LVS、LFS、Glide 和 WAC 载具。
[*] 载具状态会被保存，你也会被放回原来的座位。
[*] 被冻结的载具保持冻结。
[/list]

[b]防卡住[/b]
[list]
[*] 如果存档位置被阻挡，你会被移到最近的空闲位置。
[*] 五种方法：已知的安全位置、位置周围、导航网格、地图出生点、任意出生点。
[*] 管理员可以选择启用哪些方法及其顺序，以及搜索的距离和时间。
[/list]

[b]服务器所有者[/b]
[list]
[*] 每个玩家设置都有服务器默认值，管理员可以锁定其中任何一个。
[*] 死亡时清理（不清理、整张地图、该玩家的物体，或其已保存的物体）以及断开连接时清理。
[*] 恢复时可以遵守 Sandbox 的生成权限和 sbox 限制。
[*] 每位玩家的载具数量和存档数量上限。
[*] 通过 CAMI 管理权限（ULX 等）；在 ULX 中它们位于单独的 Rareload 分类下。
[*] 没有管理模组？自己决定谁拥有每项权限：[b]rareload perms set <权限> <user|admin|superadmin>[/b]，或者只授予某一位玩家：[b]rareload perms set <权限> <玩家>[/b]。
[*] 当存档中的某些内容无法归还时（没有权限，或被服务器拒绝），玩家会被告知是哪些内容，报告卡上也会显示。
[*] 兼容物品保护插件（CPPI）。
[/list]

[b]调试工具（管理员）[/b]
[list]
[*] 每次存档和恢复的报告卡：每个步骤、耗时，以及物体被跳过的原因（缺少插件、缺少模型、生成上限……）。
[*] 世界显示：已保存玩家和物体的信息面板、存档位置的幻影、高亮和连接线。
[*] 编辑已保存的物体：冻结、重力、删除，或在 JSON 编辑器中修改其数据。
[*] 传送到存档位置和已保存的物体。
[/list]

[b]开发者[/b]
[list]
[*] 钩子 [b]RareloadCanSave[/b] 和 [b]RareloadCanRestore[/b]（玩家、原因、部分）：返回 false（可附带一条消息）即可拒绝整个存档或恢复，或只拒绝其中一部分。
[*] [b]RareloadSaved[/b] 和 [b]RareloadRestored[/b] 在存档或恢复完成后调用。
[/list]

[h2]使用方法[/h2]

[b]Rareload 工具[/b]（[b]Tools > Rareload > Rareload[/b]）：
[list]
[*] [b]左键：[/b]保存在你瞄准的位置。
[*] [b]右键：[/b]保存在你站立的位置。
[*] [b]换弹键：[/b]执行在存档时间线中选择的操作（默认：回到上一个存档）。
[/list]
工具面板里是你自己的设置，以及存档和打开存档时间线的按钮。

[b]服务器与显示设置：[/b]
[list]
[*] [b]Utilities > Rareload > 服务器：[/b]服务器设置、玩家默认值与锁定、防卡住方法（需要 rareload_settings 权限）。
[*] [b]Utilities > Rareload > 客户端：[/b]世界显示在你屏幕上的样子。
[/list]

[b]控制台：[/b]输入 [b]rareload help[/b] 查看所有命令（存档、时间线、设置、权限、防卡住、调试），输入 [b]rareload perms[/b] 查看每项权限以及谁拥有它。

[h2]语言[/h2]
英语、法语、德语、西班牙语、荷兰语、波兰语、巴西葡萄牙语、俄语、土耳其语和简体中文。Rareload 会跟随你的 Garry's Mod 语言。

[h2]说明[/h2]
[list]
[*] 只保存你自己生成的物体，绝不保存其他玩家的物体或地图自带的物品。
[*] 来自未安装插件的物体无法恢复；报告卡会告诉你是哪些。
[*] Rareload 可在 Sandbox 以及基于 Sandbox 的游戏模式中运行（其他游戏模式可在服务器设置中启用）。
[*] Rareload v4 的存档不会保留。
[/list]

[h2]安装[/h2]
[olist]
[*] 在 Steam 创意工坊订阅 Rareload。
[*] 重启 Garry's Mod 或你的服务器。
[*] 在 [b]Tools > Rareload[/b] 打开 Rareload 工具，在 [b]Utilities > Rareload > 服务器[/b] 打开服务器设置。
[/olist]
